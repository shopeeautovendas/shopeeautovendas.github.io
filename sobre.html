Shopee AutoVendas

Organização de conteúdo, planejamento e gerenciamento de publicações para marketing de afiliados.

Independent content management and scheduling tool.

Sobre o projeto

O Shopee AutoVendas é uma ferramenta independente desenvolvida para uso interno da Ornato Casa.

Seu objetivo é simplificar a organização de produtos e conteúdos comerciais, permitindo que o responsável revise, planeje e autorize suas publicações.

Funcionalidades

Pesquisa de produtos

Consulta de produtos utilizando a API de afiliados da Shopee.

Criação de conteúdo

Modelos editáveis de legendas, títulos e descrições comerciais.

Planejamento

Organização de imagens, links, conteúdos e horários de publicação.

Instagram

Integração para preparação de imagens, consulta de status e agendamento de fotos autorizadas.

Pinterest

Agenda manual para preparação individual de Pins, títulos, descrições e links.

Controle de publicações

Revisão de conteúdo, autorização individual e controle de agendamentos.

Integração planejada com o Pinterest

O projeto pretende integrar a API oficial do Pinterest para permitir o gerenciamento de publicações na conta comercial da Ornato Casa.

Cada Pin será selecionado, revisado e autorizado individualmente pelo responsável.

A integração dependerá da aprovação do Pinterest e utilizará o fluxo oficial de autorização OAuth.

O aplicativo não possui acesso aprovado à API do Pinterest neste momento.

Uso responsável

O projeto não foi desenvolvido para geração de spam, manipulação de métricas, criação de contas em massa ou engajamento artificial.

Os conteúdos comerciais devem apresentar informações verdadeiras, identificação de publicidade e transparência sobre a utilização de links de afiliados.

About the application

Shopee AutoVendas is an independent content management tool developed for Ornato Casa's internal affiliate marketing activities.

Its features include product organization, editable caption templates, content planning and individually authorized publication schedules.

Planned Pinterest integration

The application intends to use the official Pinterest API to manage individually selected and approved Pins for the operator's own Pinterest business account.

The operator will review each Pin, including its image, title, description, destination link and publication schedule.

Pinterest API access has not yet been approved. The current Pinterest planner operates manually. Any future integration will use official OAuth authorization.

The application is not intended for spam, scraping, artificial engagement, account creation or manipulation of platform metrics.
