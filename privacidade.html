1. Sobre o aplicativo

O Shopee AutoVendas é uma ferramenta independente, desenvolvida para uso interno da Ornato Casa, destinada à organização de conteúdo de marketing de afiliados e ao planejamento de publicações.

O aplicativo não é um serviço oficial da Shopee, do Instagram ou do Pinterest.

2. Dados tratados

O aplicativo utiliza informações de produtos, imagens, links de afiliados, legendas, títulos, descrições, datas e horários de publicações.

A integração autorizada com o Instagram utiliza identificadores da conta e das mídias necessárias à preparação, publicação e consulta de status.

3. Integração com o Pinterest

Atualmente, a agenda Pinterest funciona de maneira manual. O aplicativo ainda não possui acesso aprovado à API do Pinterest.

Uma futura integração utilizará a API oficial e o fluxo de autorização OAuth, após aprovação do Pinterest.

Cada Pin deverá ser escolhido e autorizado individualmente. O aplicativo não solicitará senhas ou cookies de sessão do Pinterest.

Informações obtidas pela API do Pinterest não serão armazenadas, compartilhadas ou utilizadas para outras finalidades, salvo quando expressamente permitido pelas políticas aplicáveis do Pinterest.

4. Finalidade do tratamento

Os dados são utilizados para organizar produtos, preparar conteúdo, gerenciar agendamentos autorizados, consultar resultados operacionais e identificar falhas técnicas.

5. Armazenamento e segurança

O aplicativo utiliza o armazenamento local do navegador, GitHub Pages para hospedagem e serviços Cloudflare Workers e D1 para processamento e armazenamento dos agendamentos enviados ao servidor.

As credenciais das integrações atuais são mantidas no servidor, utilizando os recursos de proteção de segredos da Cloudflare.

As operações protegidas exigem uma chave privada de acesso. Registros técnicos poderão ser mantidos para diagnóstico e segurança.

6. Compartilhamento

O aplicativo não comercializa dados pessoais. O processamento de informações pode envolver os serviços de infraestrutura e as plataformas integradas, conforme necessário para executar as funcionalidades autorizadas.

7. Retenção e exclusão

Os registros são mantidos enquanto necessários ao gerenciamento das publicações e à operação do aplicativo.

Dados locais podem ser removidos pelo navegador. Rascunhos elegíveis podem ser excluídos do banco de dados pelo aplicativo. Outras solicitações de acesso, correção ou exclusão podem ser enviadas ao responsável pelo projeto.

Autorizações de plataformas externas podem ser revogadas nos respectivos serviços. A revogação não remove automaticamente publicações anteriores.

Privacy Policy

Last updated: November 27, 2026.

1. About the application

Shopee AutoVendas is an independent content management and scheduling tool developed for Ornato Casa's internal affiliate marketing activities.

It is not an official service of Shopee, Instagram or Pinterest.

2. Information processed

The application processes product information, images, affiliate links, captions, titles, descriptions and publication schedules.

The authorized Instagram integration processes account and media identifiers required for content preparation, publishing and status checks.

3. Pinterest integration

The Pinterest content planner currently operates manually. The application does not currently have approved Pinterest API access.

Any future integration will use the official Pinterest API and OAuth authorization following Pinterest approval.

Each Pin must be individually selected and authorized for publication. Pinterest passwords and session cookies will not be requested.

Information obtained through the Pinterest API will not be stored, shared or used for unrelated purposes unless expressly permitted by applicable Pinterest policies.

4. Purpose

Information is used to organize products, prepare content, manage authorized schedules, check operational results and troubleshoot errors.

5. Storage and security

The application uses browser local storage, GitHub Pages for hosting, and Cloudflare Workers and D1 for server-side processing and storage of submitted schedules.

Current integration credentials are protected using Cloudflare server-side secrets. Protected operations require a private access key. Technical logs may be retained for troubleshooting and security.

6. Information sharing

The application does not sell personal data. Infrastructure providers and authorized platforms may process information as necessary to provide the application's functions.

7. Retention and deletion

Records are retained as necessary for content management and application operations.

Local records can be removed through the browser. Eligible server-side drafts can be deleted through the application. Other access, correction or deletion requests may be submitted to the project operator.

Platform permissions may be revoked through the respective platform settings. Revocation does not automatically remove previously published content.
